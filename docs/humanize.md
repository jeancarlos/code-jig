# Humanize: Remove AI giveaways from code

The humanize tool removes common signs that code was generated by an LLM, making AI-assisted code indistinguishable from hand-written work. It runs automatically after the watermark stripper on every file write/edit through Claude Code or Codex.

## What it removes

1. **Boilerplate comments**: Lines that are pure LLM boilerplate markers, removed entirely:
   - "Example usage:", "Example:", "Example output:"
   - "Add more as needed", "Rest of the code", "... existing code ...", "Your code here"
   - "Certainly", "Here's the updated", "I hope this helps", "Let me know if", "As an AI", "As an assistant"

2. **Typography**: Deterministic rewrites in comments and prose files only (`.md`, `.txt`, `.rst`, `.py`, `.js`, `.ts`, etc.):
   - Em dashes (-), en dashes (-), horizontal bars (-) → single dash
   - Curly quotes (' ' " ") → ASCII quotes
   - Ellipsis character (…) → three dots

3. **Emoji**: Removed from code comments (preserved in `.md` prose)

4. **Language support**: Python, JavaScript/TypeScript, Shell, CSS, Go, Rust, Java, C/C++/C#, Ruby, YAML/TOML

## When it runs

- **Claude Code**: Immediately after Write, Edit, MultiEdit, NotebookEdit tools (PostToolUse hook)
- **Codex**: At end of session (Stop hook sweep)

## CLI

```bash
harness humanize --check <file-or-dir>   # dry-run: report what would change
harness humanize <file-or-dir>            # apply transformations
```

## Implementation details

- Comments detected per-language (# for Python/Shell, // and /* */ for C-style, etc.)
- Only line-leading and full-line comments are processed; inline comments are skipped
- No changes to code or prose unless it detects boilerplate/typography issues
- File mode, CRLF line endings, and BOM preserved
- Binary files and symlinks skipped
- Fails gracefully: errors logged to stderr, never block the tool

## Coordination with ai-gate

This machine runs `/home/jean/.config/git/hooks/ai-gate.py` on commit, which catches invisible characters and other watermarks at the git level. The humanize tool works in tandem: it removes visible AI giveaways before code reaches git, and ai-gate is the final fallback.

## Boilerplate phrase list

The following phrases are detected case-insensitively and removed as whole comment lines:

- "Example usage:", "Example output:", "Example:", "Add more as needed"
- "Rest of the code", "... existing code ...", "... your code ..."
- "Your code here", "Certainly", "Here's the updated", "Here is the updated"
- "I hope this helps", "Let me know if", "As an AI", "As an assistant"

Additions should be made as data in `harness/humanize.py` (LLM_BOILERPLATE list), not as code logic.
